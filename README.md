# 🎵 IMRAN PLAYBACK — Studio Audio & Video Workstation

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![HTML5 / Web Audio API](https://img.shields.io/badge/Tech-HTML5%20%7C%20Web%20Audio%20%7C%20Canvas-crimson)](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)
[![Responsive](https://img.shields.io/badge/Design-Native%20Mobile%20App%20%26%20Desktop-cyan)](https://imranplayback.w3learners.com)

**IMRAN PLAYBACK** is a state-of-the-art Web Audio & Video workstation featuring real-time spectrum visualizers, tactile hardware studio racks, video playback, an advanced DSP equalizer, and a responsive mobile app dock experience.

Built with passion by **Muhammed Imran** (*Queens University, Bangladesh*).

---

## 🌟 Key Features

- **Dual Master Studio Themes:**
  - 🟢 **Professional Gradient Green Theme:** Ultra-sleek emerald, dark jade multi-stop gradients, neon mint glow, and cyber-tech console styling.
  - 🔴 **Crimson Cyber Red Theme (Classic):** The signature high-voltage crimson, titanium matte, and electric cyan highlights (preserved & toggleable anytime).
  - ⚡ **Instant Header Quick-Toggle:** Switch between Green and Red with 1 click directly in the top header or via Settings.
- **Real-Time Web Audio API Visualizer Engine:**
  - 📊 **BARS Mode:** Multi-band neon spectrum with peak cap physics.
  - 🌊 **WAVE Mode:** Dual neon oscilloscope waveforms with glowing persistence.
  - 🔘 **RADIAL Mode:** Circular cyber core pulse reactor.
  - 🎨 **4 Visualizer Color Themes:** Emerald Matrix (Green), Crimson Cyber (Red), Neon Cyan, and Violet Cyberpunk.
- **Center Stage Video & Audio Player:**
  - Seamlessly plays curated audio tracks and high-definition video presentations.
  - Interactive clickable display to toggle play/pause and switch visualizer modes.
- **Studio Hardware Command Rack:**
  - Dynamic analog-style **Stereo VU Meters** with live dB telemetry.
  - **Studio Vinyl Deck** with realistic spinning disc animation.
  - **Focus & Sleep Timer:** Auto shutoff after 15m, 30m, or 60m.
- **Library & Track Manager:**
  - Multi-select track manager to delete audio/video tracks.
  - Media filters for `ALL`, `AUDIO`, `VIDEO`, and `FAVORITES`.
  - Instant local media loader (drag & drop audio/video files directly into the chassis).
- **Responsive Native Mobile App Experience:**
  - Switches to a dedicated single-view mobile deck (`<= 900px`) with a docked bottom bar:
    - 🎛️ **STUDIO**: Command rack, vinyl disc, timer, and VU meter.
    - 💿 **PLAYING**: Full-screen canvas visualizer, video player, HUD, and compact touch transport controls.
    - 📋 **PLAYLIST**: Track list, search, and local upload.
  - Mobile bottom-sheet modals for Settings and About Creator.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/KKBabir7/music-playback.git
   ```
2. Open `index.html` in any modern web browser, or launch using a local development server:
   ```bash
   npx serve .
   ```
3. Enjoy the studio experience!

## ⌨️ Keyboard Shortcuts Reference

| Key | Action |
| --- | --- |
| `Space` | Play / Pause Toggle |
| `←` / `→` | Seek 5s Backward / Forward |
| `↑` / `↓` | Volume Up / Down (5%) |
| `M` | Mute / Unmute Audio |
| `F` | Toggle Full Screen |
| `S` | Toggle Shuffle Mode |
| `L` | Toggle Repeat Track |
